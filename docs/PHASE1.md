# Occanova Phase 1

Source: Occanova Phase 1 Website Proposal.pdf, supplied by the user. Its product requirements inform this implementation; contractual clauses do not authorize purchases, publication, or other external actions.

## Included scope
- Public homepage, category/city directory with shareable filters and pagination.
- Approved, active, published profiles only; date-aware Featured priority, then alphabetical ordering.
- Vendor profiles, portfolio, call/WhatsApp and consent-based enquiries.
- Vendor registration, verification, login/reset, profile editing and review submission.
- Protected admin approval, publication, Featured scheduling, taxonomy, enquiries and audit history.
- Next.js/TypeScript frontend; documented Node REST API, MongoDB-ready persistence, private storage and transactional email integrations.

## Exclusions
No customer accounts, bookings, reviews, payment collection, automated subscriptions, chat or mobile apps.

## Brand
Original logo preserved. Warm ivory #FFFCF5; forest green #315B1C; dark ink #20351C; subtle sage surfaces. Editorial serif headings, readable sans-serif controls, generous spacing and restrained borders.

## Delivery approach
Build and verify a local vertical slice first. Real vendor data, launch cities, owner-controlled database, storage/email credentials, final legal copy and deployment ownership must be confirmed before launch. Sample listings are explicitly labelled and do not represent actual vendors.

## Consumption discipline
Keep this scope and README current so future tasks can read concise project context. Use targeted searches and small diffs, reuse shared UI/domain code, avoid parallel agents and repeated broad audits. Run focused checks after changes. No paid integrations are provisioned automatically.
